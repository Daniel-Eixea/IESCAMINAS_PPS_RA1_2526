# Requisitos
Para poder ejecutar la aplicación de shell en Windows se ha utilizado ``Git Bash 2.47.1.windows.1 o superior``.

# Ejecución
Para ejecutar la aplicación ejecutaremos Git Bash y usaremos el comando (Si estamos en el directorio de la aplicación):
````
.\app_bash.sh
````
En caso de estar en otro directorio usaremos:
````
Ruta/a/la/aplicación.sh
````

# Requisitos
``python 3.13.1 o superior``

# Ejecución
Para ejecutar la aplicación usaremos el comando (Si estamos en el directorio de la aplicación):
````
python .\app_cifrado.py
````
En caso de estar en otro directorio usaremos:
````
python Ruta/a/la/aplicación.py
````
# Tests
Para los test se ha utilizado ``pytest 9.0.2`` y para ejecutar los test utilizaremos:
````
pytest
````
Con el comando anterior ejecutaremos todos los test destro del projecto (Tenemos que estar dentro de la carpeta principal), si no escontramos en otra ruta usaremos el comando:
````
pytest Ruta/a/los/test
````
Si queremos ver mas informacon sobre los test usaremos la opcion **``-v``**:
````
pytest -v
````
